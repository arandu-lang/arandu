# Error T003: Incompatible Argument

This error occurs when passing an argument type that does not match the parameter type of the called function.

## Incorrect Code Example

```arandu
func greet(name: str) {}
func main() {
    greet(42)
}
```

## Semantic Explanation

Functions have strict type signatures. The types of arguments at the call site must unify with the parameter types in the function definition.

Computed constant generic arguments also require an integer result. An explicit
`count<comptime (expression)>()` argument must be non-negative and fit the
existing `u64` constant-key domain; boolean and unit results are not converted
implicitly. Use an integer expression or an explicitly typed integer helper.
T011 separately checks whether a valid constant key fits the declared parameter
type, such as `u8` or target-sized `usize`.

## How to Fix

Pass the expected type:

```arandu
func greet(name: str) {}
func main() {
    greet("Bruno")
}
```
