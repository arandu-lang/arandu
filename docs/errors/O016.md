# Error O016: Cannot Move Out of a Reference

A reference lends a value without giving up ownership. Consuming a value that
is not `Copy` through a `ref T` or `mut ref T` (`*r`, or a field reached
through `r`) would create a second owner: the original owner still uses the
value and destroys it later, so it would be destroyed twice. Reading a value
in place, such as matching on `*r` or calling a method through `r`, does not
consume it.

## Incorrect Code Example

```arandu
import std.alloc.string as strings

func take(s: strings.String): void {}

func forward(r: ref strings.String): void {
    take(*r) // error O016
}
```

The same applies to a closure that consumes a value it only borrows. A
callback borrows the locals it reads, so consuming one inside the body moves
it out of the caller:

```arandu
import std.alloc.string as strings

func take(s: strings.String): void {}
func each(f: () -> void): void { f() }

func main(): int {
    let s = strings.String.from("a")
    each(() => take(s)) // error O016
    return 0
}
```

## Correct Code Example

Use the value through the reference, with a method, a field or `ref`:

```arandu
import std.alloc.string as strings

func size(r: ref strings.String): int {
    return r.asStr().len() as int
}
```

To give a closure its own copy of the value, capture it with `move`. A
borrowed callback may be called many times, so it still cannot consume the
moved value; a closure that runs once and consumes its captures is an owned
closure (`own (A) -> R`, planned for RFC 0032 L3).
