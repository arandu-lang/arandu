# Error T101: Static Without a Data Image

A `static mut` is writable storage that starts as constant bytes in the
program's data section, like a global variable in C. Its initial value is
evaluated at compile time and written into the executable; no user code runs
before `main` to initialize it.

Text, byte views and slices point at other data: that data becomes read-only
objects of the image, and the pointer words are filled with their addresses.
What has no image is an enum whose layout hides its tag in a niche of its
payload or in the bits of a pointer, which needs a proof about that payload,
or a value of a type that does not lay out at all.

## When It Appears

Values the compiler can evaluate are scalars, text, byte views, arrays,
tuples, structs and tagged enums, and all of them have images. The error
remains as a guard: a layout whose tag lives in a niche or in pointer bits
is never written without a proof about its payload, and a value whose type
has no layout is refused instead of being written wrong.

## Correct Code Example

Use a representation with an explicit tag, or build the value at run time:

```arandu
static mut NAME: str = "arandu"
static mut NAMES: [3]str = ["a", "bb", "ccc"]
static mut COUNTER: int = 0

func bump(): int {
    unsafe {
        COUNTER = COUNTER + 1
        return COUNTER
    }
}
```

Scalars, text, byte views, arrays, tuples, structs, enums with an explicit
tag and `nil` pointers are supported.
