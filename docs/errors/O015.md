# Error O015: Cannot Move Out of an Indexed Place

A value whose type has a destructor cannot be moved out of an array, slice or
`Vec` element with `base[i]`. The container still owns that element and
destroys it later, so the moved copy would be destroyed twice.

## Incorrect Code Example

```arandu
import std.alloc.vec as vec
import std.alloc.string as strings

func main(): int {
    let mut names = vec.Vec<strings.String>.new()
    names.push(strings.String.from("ada"))
    let first = names[0]
    return first.len() as int
}
```

## Correct Code Example

Borrow the element instead, or take it out with an operation that removes it
from the container:

```arandu
import std.alloc.vec as vec
import std.alloc.string as strings

func main(): int {
    let mut names = vec.Vec<strings.String>.new()
    names.push(strings.String.from("ada"))
    let first = ref names[0]
    return first.len() as int
}
```
