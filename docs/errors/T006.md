# Error T006: Type Not Nullable

This error occurs when assigning `nil` to a variable that is not explicitly optional or nullable.

## Incorrect Code Example

```arandu
func main() {
    x: int = nil
}
```

## Semantic Explanation

By default, values in Arandu cannot be nil. To allow nil, you must use pointer types or optional types.

## How to Fix

Make the type nullable by declaring it as a pointer:

```arandu
func main() {
    x: ptr[int] = nil
}
```

## Nullable Types That Own Resources

`T?` is a plain value-or-nil: it is copied freely and never destroyed. A type
that owns resources, such as `String` or `Vec<T>`, therefore cannot be made
nullable, because its buffer would be freed twice or leaked.

```arandu
import std.alloc.string as strings

func greet(name: strings.String?): int {
    return 0
}
```

Use `Option<T>`, which moves and destroys its payload:

```arandu
import std.alloc.string as strings

func greet(name: Option<strings.String>): int {
    return 0
}
```
