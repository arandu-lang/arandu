# Error T100: Borrowed Callback Escapes

A parameter of function type `(A) -> R` is a borrowed, non-escaping callback.
The caller passes a closure that may refer to its own locals, and the callee is
specialized for that closure. The callback is only valid while the call that
received it runs, so the callee may call it or pass it on to another callback
parameter, but it may not let the callback outlive the call.

Returning the callback, storing it in a struct field, or assigning it to a
variable or parameter declared with a function type is rejected:

```arandu
struct Handler {
    run: (int) -> int,
}

func keep(f: (int) -> int): int {
    let handler = Handler { run: f } // error T100: the callback would escape
    return 0
}
```

Call the callback where it is received, or pass it on to another callback
parameter:

```arandu
func apply(x: int, f: (int) -> int): int {
    return f(x)
}

func twice(x: int, f: (int) -> int): int {
    return apply(apply(x, f), f)
}
```

Owned closures that may escape, written `own (A) -> R`, are planned for a later
release (RFC 0032, L3).
