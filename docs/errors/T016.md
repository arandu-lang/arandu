# Error T016: Invalid Try Operator

This error occurs when applying the `?` operator to a value that is not a `Result` or `Option`, or when the enclosing function cannot propagate that value's error/absence case.

## Incorrect Code Example

```arandu
func main() {
    x = 10
    y = x?
}
```

## Semantic Explanation

The try operator `?` checks a `Result` or `Option`, returns its success value, and propagates its error/absence case from the current function. The function must return a compatible `Result` or `Option`; otherwise the generated return path would not have the function's declared type.

## How to Fix

Use `?` in a function whose return type can carry the propagated case:

```arandu
func perform(): Result<int, str> {
    return Result.Ok(10)
}
func wrapper(): Result<int, str> {
    let value = perform()?
    return Result.Ok(value)
}
```
