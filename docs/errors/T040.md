# Error T040: Division By Zero

An integer expression attempts to divide or compute the remainder (`%`) with
a literal divisor of zero. Arandu rejects integer division by zero at compile
time whenever the divisor is known to be zero. Explicit compile-time integer
evaluation also reports this error when its computed divisor is zero.

Floating-point division follows IEEE semantics: a nonzero finite value divided
by signed zero produces a signed infinity, and zero divided by zero produces
NaN. It does not use this integer diagnostic. `%` remains an integer operator.

For example, dividing by zero:

```arandu
let x = 42 / 0
```

Or computing the remainder with zero:

```arandu
let y = 10 % 0
```

## How to Fix

Ensure that the divisor is non-zero, or handle zero values with a conditional
check:

```arandu
let x = 42 / 2
```
