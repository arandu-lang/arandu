# Arandu 0.1.9 — relatório de promoção

**Estado:** tag criada; validação de distribuição reprovada no Windows.

**Canal:** candidata do SDK Arandu v0.1; promoção de distribuição bloqueada.

A PR #32 foi integrada com `S0 / Gate` aprovado. A tag `v0.1.9` foi criada no
commit `ab717953`. O smoke do SDK empacotado falhou no runner Windows ao executar
`arandu build` no projeto `corpus/medium/comptime_core`:

```text
LINK : fatal error LNK1181: cannot open input file '.obj'
```

O resultado bloqueia a validação da distribuição; o gate do código-fonte não
substitui essa prova. A falha não comprova indisponibilidade geral do compilador
nem falha nas outras plataformas. A investigação e correção da linkedição
pertencem à 0.1.10; não mova a tag nem sobrescreva os artefatos da 0.1.9.

- [x] Contrato tag ↔ componentes verde: `xtask check-release-contract v0.1.9`
  validado localmente no Linux, com 27 manifestos alinhados.
- [x] Commit alcançável pela `main` e PR #32 com `S0 / Gate` verde.
- [ ] Packages Linux x86-64, macOS ARM64 e Windows x86-64 instalados.
- [ ] Checksums, manifest e provenance verificados.
- [ ] Archives públicos baixados, instalados e aprovados no corpus.
- [ ] Artifact `rc-evidence-v0.1.9` preservado.
- [ ] Nenhum bloqueador conhecido permanece aberto.

## Validação local

No Linux, passaram formatação, `cargo check`, Clippy com todos os targets e
features e warnings negados, testes do workspace, rustdoc com warnings negados,
documentação de diagnósticos, arquitetura, finais de linha e taxonomia dos docs.
O emissor C passou 100 regressões; o fuzzer passou 132 testes, com dois perfis
manuais ignorados, incluindo a seed 8 em todos os níveis de otimização.

Esses resultados não substituem o S0 do PR nem as provas de distribuição e
instalação pública listadas acima.

## Resultado

- Tag: `v0.1.9`

- Workflow: smoke de distribuição reprovado no Windows.

- macOS ARM64: prova de distribuição não registrada neste relatório.
