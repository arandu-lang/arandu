# Error O019: Raw Pointer or Unsafe Cast Requires `unsafe`

Operations that dereference a raw pointer (`ptr[T]`), perform pointer
arithmetic, read or write fields or elements through a raw pointer, call a
pointee method through a raw pointer, or reinterpret bits across unsafe type
boundaries (`ref T as ptr[T]`, `Coroutine[T] as ptr[u8]`, `int as T`) must
appear inside an `unsafe` block.

## Incorrect Code Example

```arandu
struct Node { value: int }

func readValue(p: ptr[Node]): int {
    return p.value // error O019
}

func forge<T>(bits: i64): T {
    return bits as T // error O019
}
```

## Correct Code Example

Wrap raw-pointer dereferences and unsafe casts in an explicit `unsafe` block
after verifying the safety preconditions (non-null, aligned, valid lifetime,
matching bit representation):

```arandu
struct Node { value: int }

func readValue(p: ptr[Node]): int {
    unsafe {
        return p.value
    }
}
```
