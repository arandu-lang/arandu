# T047: Invalid target type layout

The requested type does not have a finite, concrete layout on the selected
target. `@sizeOf(Type)` and `@alignOf(Type)` return target `usize` values, not
properties of the computer running the compiler.

Use a concrete type with resolved array lengths and finite by-value fields.
An excessively large array or aggregate can exceed the target object-size
limit. A generic type must be specialized before its layout is evaluated.

```arandu
func main(): usize {
    return @sizeOf([18446744073709551615]u64)
}
```

Reduce the array length, or use indirection for recursive data instead of
embedding the same type by value. The legacy `mem.sizeOf<T>()` and
`mem.alignOf<T>()` APIs use the same target layout rules.
