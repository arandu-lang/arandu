# Error T048: Invalid Array Repetition

An array repeat expression `[value; N]` evaluates `value` once and constructs
an array with a static length. Use an integer literal, an integer `comptime`
parameter, or an explicit `comptime (expression)` for the length.

When the length exceeds one, the element must be Copy. Repeating a buffer
owner or an exclusive reference would duplicate ownership; the compiler never
inserts an implicit clone. A length of one moves the initializer normally.
A length of zero still evaluates the initializer and cleans up its resources.

```arandu
func flags<comptime N: uint>(): [N]bool {
    return [false; N]
}
```

For non-Copy elements, construct each element independently instead of
duplicating one owner. Excessive repetition is rejected before allocating
expanded compiler IR; this implementation allows at most 65,536 elements.
The complete target layout, including nested arrays, must also fit the current
backend allocation interface (at most 4,294,967,295 bytes). Larger layouts are
rejected before lowering their initializer rather than truncating byte counts.

An exclusive reference is not Copy and cannot be repeated twice:

```arandu
func example(): void {
    let mut value = 0
    let refs = [mut ref value; 2] // error T048: duplicates an exclusive borrow
}
```

If only one reference is needed, a length of one transfers it without copying:

```arandu
func example(): void {
    let mut value = 0
    let refs = [mut ref value; 1]
}
```

For multiple independent owners or exclusive references, initialize separate
values and borrow each one individually. Making a type Copy is appropriate
only when duplicating all of its contents preserves ownership semantics.
