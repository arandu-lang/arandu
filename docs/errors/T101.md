# Error T101: Static Without a Data Image

A `static mut` is writable storage that starts as constant bytes in the
program's data section, like a global variable in C. Its initial value is
evaluated at compile time and written into the executable as plain bytes; no
code runs before `main` to initialize it.

Some values have no plain-bytes image: a `str` or byte view points at other
data, and an enum whose layout hides its tag in a niche of the payload needs a
proof about that payload. Such a value cannot be the initial value of a
`static mut`.

## Incorrect Code Example

```arandu
static mut NAME: str = "arandu" // error T101: a string points at other data
```

## Correct Code Example

Store plain data in the static and build richer values at run time:

```arandu
static mut COUNTER: int = 0
static mut FLAGS: [4]u8 = [0, 0, 0, 0]
static mut HEAD: ptr[u8] = nil

func bump(): int {
    unsafe {
        COUNTER = COUNTER + 1
        return COUNTER
    }
}
```

Scalars, arrays, tuples, structs, enums with an explicit tag and `nil`
pointers are supported.
