# Error T043: Runtime Value Captured by Comptime

A `comptime` root cannot read or write a runtime local or parameter declared
outside that root, even when the local has a literal initializer.

```arandu
func example(input: int): int {
    return comptime input // error T043
}
```

Declare compile-time locals inside the `comptime` block, pass constant arguments
to a pure helper inside the root, or use an ordinary global constant. The
diagnostic points to both the captured use and its runtime declaration.
It also explains that runtime local values and parameters do not exist during
compilation, and suggests compile-time locals or global constants instead.
The same rule applies to a `comptime if` condition. A runtime binding that
shadows a global constant is still a capture; a literal initializer does not
turn that binding into a compile-time constant.
