# Error T047: Invalid Target Type Layout

The requested type does not have a finite, concrete layout on the selected
target. `mem.sizeOf<T>()` and `mem.alignOf<T>()` return target `usize` values, not
properties of the computer running the compiler.

Use a concrete type with resolved array lengths and finite by-value fields.
An excessively large array or aggregate can exceed the target object-size
limit. A generic type must be specialized before its layout is evaluated.

```arandu
import std.core.mem as mem

func main(): usize {
    return mem.sizeOf<[18446744073709551615]u64>() // error T047: object is too large
}
```

Use a representable array length:

```arandu
import std.core.mem as mem

func main(): usize {
    return mem.sizeOf<[4]u64>()
}
```

Target dependence alone is valid. For example, `mem.sizeOf<usize>()` and
`mem.alignOf<usize>()` are evaluated using the selected target's pointer layout;
code must not assume that compiling on a 64-bit host makes them eight bytes
for every target. T047 reports an invalid or unresolved layout, rather than
rejecting a valid layout merely because it differs between targets.

Reduce the array length, or use indirection for recursive data instead of
embedding the same type by value. The compatible `@sizeOf(Type)` and
`@alignOf(Type)` expression forms use the same target layout rules.
