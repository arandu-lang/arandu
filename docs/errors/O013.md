# Error O013: Unsafe Call Requires `unsafe`

Calling FFI/`extern` operations or a function annotated `@Unsafe` must be
nested in `unsafe` so the boundary is explicit. An `@Unsafe` function promises
that its documented preconditions cannot be checked by the compiler; callers
must uphold them before entering the block.

## Incorrect Code Example

```arandu
@Unsafe
public func readRaw(pointer: ptr[u8]): int { return 0 }

func main(): int {
    let pointer: ptr[u8] = nil
    return readRaw(pointer)
}
```

## Correct Code Example

```arandu
@Unsafe
public func readRaw(pointer: ptr[u8]): int { return 0 }

func main(): int {
    let pointer: ptr[u8] = nil
    unsafe {
        // The caller must ensure pointer is valid for the callee's contract.
        return readRaw(pointer)
    }
}
```
