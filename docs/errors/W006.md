# Warning W006: Unhandled Result

This warning occurs when a function returns a `Result` type but the caller discards it without checking or propagating.

## Incorrect Code Example

```arandu
func save(): Result<void, str> {
    return Result.Ok(nil)
}
func main(): int {
    save()
    return 0
}
```

## Semantic Explanation

Discarding `Result` values silently ignores potential errors, making applications fragile and hard to debug.

## How to Fix

Handle both variants, or propagate the error from a function that also returns `Result`:

```arandu
func save(): Result<void, str> {
    return Result.Ok(nil)
}
func main(): int {
    let _, _ = save()
    return 0
}
```

Inside a `Result`-returning function, use `?` instead:

```arandu
func run(): Result<void, str> {
    save()?
    return Result.Ok(nil)
}
```
