# Warning W010: Implicit Copy of Large Value

A value whose type is structurally `Copy` and whose target layout size is at
least 256 bytes was implicitly duplicated while the original binding was still
live.

Because Arandu derives `Copy` structurally for plain-old-data types, large
arrays or structs composed purely of scalar fields can be copied silently when
passed by value and reused afterward. Last-use transfers are elided to moves and
do not trigger this warning.

## Code Example

```arandu
struct Matrix {
    cells: [64]f64, // 512 bytes
}

func sum(m: Matrix): f64 {
    return m.cells[0]
}

func main(): f64 {
    let m = Matrix { cells: [1.0; 64] }
    let a = sum(m) // warning W010: `m` is duplicated while still live
    let b = sum(m)
    return a + b
}
```

## How to Fix

Borrow the value with `ref T` when the callee only needs to read it:

```arandu
func sum(m: ref Matrix): f64 {
    return m.cells[0]
}
```

Or annotate the type with `@NoCopy` if implicit duplication should be forbidden
by the type's ownership contract:

```arandu
@NoCopy
struct Matrix {
    cells: [64]f64,
}
```

If the copy is intentional, suppress the warning locally with
`@Suppress("large_implicit_copy")`.
