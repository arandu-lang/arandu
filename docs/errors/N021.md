# Error N021: Duplicate Function Symbol

Two distinct functions of the program map to the same native symbol name, so
no backend can emit both. The compiler reports the pair instead of failing in
code generation or at link time.

Function symbols are qualified by module, so this happens only when two
qualified names coincide, for example a method `Box.read` in an entry that
declares `module app` and a function `read` in `src/Box.aru`, both
`app.Box.read`.

Two `@Export` functions claiming the same linker name are reported as `T049`
instead, with the export context.

Rename one of the functions, or move one of them to another module.
