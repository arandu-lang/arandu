# Code T033: [Reserved]

This code is reserved. Until 0.3.0 it rejected a call through anything other
than a direct callee, such as a function value. Since 0.3.0 a `(A) -> R`
value is a code pointer and calling it is an indirect call on every backend
(RFC 0032, L2), so the code is no longer emitted.

The remaining limits of function values have their own codes: an `@Unsafe`
or `extern` function cannot become a value ([O013](O013.md)), and an
`@Export` function or a capturing closure cannot yet ([U001](U001.md)).
