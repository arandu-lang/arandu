# Code W008: [Reserved]

This code is reserved. Until 0.2.0 it warned about a legacy spelling of a
built-in annotation (`@no_fallback` for `@NoFallback`), which kept its
canonical meaning during the migration window. Since 0.2.0 those spellings
are unknown annotations and report [N012](N012.md), with a structured
replacement for the canonical name.
