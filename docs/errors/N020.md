# Error N020: Module Declaration Mismatch

A source file of the package being compiled declares a `module` path that is
not the module its file location defines. Every file under the package source
root is the module `<package>.<path>`: `src/net/http.aru` in package `app` is
`app.net.http`, the module `import app.net.http` names. The entry file is the
package itself, so it may only declare the package name.

```arandu
// src/outro.aru in package `app`
module app.left   // error: this file is module `app.outro`
```

A declaration that disagrees with its file would give the file two identities:
imports find it under its path while its symbols claim another module, and two
files could claim the same module.

Declare the module of the file's path, or omit the declaration; an omitted
declaration means the same module. To give the code another module path, move
the file.
