# Warning W009: Captured Copy Is Assigned but Never Read

An owning closure (`own (A) -> R`, or any lambda where one is expected) owns
what it captures: a `Copy` local is copied into the closure. Assigning to
that copy without ever reading it changes nothing: the closure never uses the
value, and the local outside keeps its own.

## Code Example

```arandu
func later(job: own () -> void) {}

func main(): int {
    let mut count = 0
    later {
        count += 1 // warning W009: `count` outside is unchanged
    }
    return count
}
```

## How to Fix

To change the original, pass the block where a borrowed callback
(`() -> R`, without `own`) is expected; it borrows the local mutably:

```arandu
func repeat(times: int, body: () -> void) {
    let mut i = 0
    while i < times {
        body()
        i += 1
    }
}

func main(): int {
    let mut count = 0
    repeat(3) {
        count += 1
    }
    return count
}
```

A closure that keeps its own state reads it, and does not warn:

```arandu
func counter(): own () -> int {
    let mut n = 0
    return () => {
        n += 1
        n
    }
}
```
