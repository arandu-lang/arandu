# Error T006: Type Not Nullable

This error occurs when assigning `nil` to a variable that is not explicitly optional or nullable.

## Incorrect Code Example

```arandu
func main() {
    x: int = nil
}
```

## Semantic Explanation

By default, values in Arandu cannot be `nil`. To allow `nil`, you must use an
optional type (`T?` / `Option<T>`) or a raw pointer (`ptr[T]`).

## How to Fix

Make the variable optional or a raw pointer:

```arandu
func main() {
    let x: int? = nil
    let p: ptr[int] = nil
}
```

`T?` is syntactic sugar for `Option<T>`, so it works uniformly with primitives,
references, and resource-owning types such as `String?` and `Vec<T>?`.
