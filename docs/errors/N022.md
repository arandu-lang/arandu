# Error N022: Name Not Bound in Every Alternative

The alternatives of an or-pattern `p1 | p2` are different ways to match the
same arm, so the arm's body must find the same names bound whichever one
matched. A name bound by some alternatives and not by others would have no
value on some paths.

## Incorrect Code Example

```arandu
enum Shape {
    Circle(int),
    Empty,
}

func size(shape: Shape): int {
    return match shape {
        Shape.Circle(n) | Shape.Empty => n, // error N022: `Empty` binds no `n`
    }
}
```

## Correct Code Example

Bind the same names in every alternative, or split the arm:

```arandu
func size(shape: Shape): int {
    return match shape {
        Shape.Circle(n) => n,
        Shape.Empty => 0,
    }
}
```

A name bound by every alternative is one variable, and it has the same type
in all of them (a different type is T002):

```arandu
enum Shape {
    Circle(int),
    Square(int),
}

func size(shape: Shape): int {
    return match shape {
        Shape.Circle(n) | Shape.Square(n) if n > 0 => n,
        Shape.Circle(_) | Shape.Square(_) => 0,
    }
}
```

A guard runs once per alternative, with the names that alternative bound.
