# Error T046: Invalid Compile-Time Integer Arithmetic

Compile-time arithmetic is checked against the declared integer type and the
selected target layout. Overflow and invalid shift amounts are errors, not
silent wrapping or host-dependent arithmetic.

```arandu
func example(): i8 {
    return comptime { let maximum: i8 = 127; maximum + 1 } // error T046
}
```

Choose a sufficiently wide integer type or correct the calculation. A valid
minimum signed literal is accepted; negating a computed minimum still
overflows. Division and remainder by zero use error T040 instead.
