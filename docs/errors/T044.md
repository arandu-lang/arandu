# Error T044: Compile-Time Evaluation Failed

The AMIR interpreter could not evaluate a `comptime` expression or one
of its retained helpers. Helpers must use admitted values/operations and have
concrete types and instance arguments. Runtime effects, external calls and indirect calls cannot be
executed by CTFE. Admission checks the retained call closure, not only the
branch executed for one input.

Use a pure admitted helper, remove runtime effects from the compile-time
calculation, or perform that work at runtime. Evaluation diagnostics include
the failing source location and a bounded call trace when available; compiler
IR IDs and debug representations are not part of their public presentation.

A static selection must not depend on the function body that selection is
needed to construct. This applies to direct and mutual dependencies between
generic instances. Move the condition into an independent pure helper, or
break the compile-time dependency cycle; ordinary bounded recursion inside an
already constructed CTFE unit remains permitted.

Global constant dependencies must also be acyclic, including dependencies across
registered imported modules and through pure helpers. A constant initializer
cannot obtain its own frozen value before that evaluation has completed.
