## Escopo

A versão incorpora as correções de estabilidade da [PR #33](https://github.com/arandu-lang/arandu/pull/33),
integrada na `main` pelo commit `edf9aff590f89dabaca2d07d9c1dc9c11222706f`.
O commit de origem `3b7c1ade6c784791643710893697c4e11aa3852e` passou no
`S0 / Gate`, incluindo portabilidade Windows/macOS e os smokes de distribuição
e de integração do SDK. A tag publicada aponta para
`7df12f7a36ed872ea6c04287cb4e536525bc5291`. O
[workflow Release 38779239029](https://github.com/arandu-lang/arandu/actions/runs/38779239029)
concluiu com sucesso os packages, integração SDK/VSIX e o download, instalação e
smoke dos archives públicos nos três alvos, incluindo o corpus CTFE aplicável.

O escopo inclui linkedição MSVC com caminhos completos curtos, correções de
casts/ABI e frontend, mutações negativas estruturais, comparação diferencial
pelos comandos reais da CLI e bisseção isolada de regressões. A preparação integrada
alinhou os componentes para 0.1.10, sem acrescentar funcionalidades.

## Procedimento histórico de promoção

A promoção exigiu o PR integrado e verde antes da tag. O procedimento abaixo
registra essa etapa; a tag existente é imutável e não deve ser recriada:

```bash
git switch main
git pull --ff-only origin main
cargo run --locked -p xtask -- check-release-contract v0.1.10
git tag -a v0.1.10 -m "Arandu 0.1.10"
git push origin v0.1.10
```

Não mova nem force a tag. O workflow exige o S0 verde do PR mergeado e executa
somente as provas exclusivas de empacotamento, publicação e instalação pública.

A evidência cobre os fluxos executados sobre esses artefatos. Não estabelece
paridade completa de async/paralelismo, freestanding, ABI pública estável ou
ausência de alocações residuais. No snapshot da release, `scripts/install.sh`
ainda podia pular a verificação SHA-256 quando nenhuma ferramenta de hash estava
disponível. Essa falha histórica foi corrigida nesta série de commits: o
instalador atual exige uma ferramenta verificadora e valida também o manifesto
BLAKE3 interno. O contrato de distribuição detalha os demais limites.
