# Error T011: Generic Constraint Not Satisfied

Constant generic arguments must also fit their declared integer parameter type.
For example, `256` cannot instantiate `<comptime N: u8>`, even though constant
instance keys use `u64` storage. This applies equally to literal and computed
arguments. `usize` and `isize` bounds use the selected target, not the host.

Forwarding a constant parameter must also preserve its entire non-negative
domain. A `<comptime M: u16>` parameter cannot be forwarded to
`<comptime N: u8>`: another legal value of `M` might exceed 255, even if today's
caller passes `1`. Declare `M` with a compatible range, or widen `N` when that
matches the callee's contract. Diagnostics label both declarations.

This error occurs when instantiating a generic function or type with a type parameter that does not satisfy its generic constraints.

## Incorrect Code Example

```arandu
interface Show {}
struct Box[T] where T: Show {}
struct User {}

func main(): {
    b = Box[User] {}
}
```

## Semantic Explanation

Generic constraints enforce that type parameters must implement specific interfaces. Instantiating a generic with a type that lacks the interface violates this.

## How to Fix

Pass a type that implements the required interface:

```arandu
interface Show {}
struct Counter {}
func Counter.show(c Counter) {}

struct Box[T] where T: Show {}
func main(): {
    // Assuming Counter satisfies Show
    b = Box[Counter] {}
}
```
