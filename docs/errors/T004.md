# Error T004: Incompatible Return Type

This error occurs when a returned value does not match its return target's type.
For ordinary functions, that target is the declared return type.

## Incorrect Code Example

```arandu
func main(): int {
    return "hello"
}
```

## Semantic Explanation

The type of the expression returned must match the return type specified in the function signature.

The compiler's internal compile-time block checker also uses this code when an
explicit return and a value-producing final expression disagree. Such a block
has its own return target: its result is not the containing function's result.
A return without a value requires `void` (unit). A value-producing block must
produce a value on every exit, including paths that reach its end. Public
`comptime` grammar is still pending; this describes the internal staging contract.

## How to Fix

Return the correct type or modify the signature:

```arandu
func main(): str {
    return "hello"
}
```
