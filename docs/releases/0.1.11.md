**Canal:** release candidate pública do SDK Arandu v0.1.

O PR de preparação deve ser mergeado e ficar integralmente verde antes da tag.
Depois, execute na `main` atualizada:

```bash
git switch main
git pull --ff-only origin main
cargo run --locked -p xtask -- check-release-contract v0.1.11
git tag -a v0.1.11 -m "Arandu 0.1.11"

```

Não mova nem force a tag. O workflow exige o S0 verde do PR mergeado e executa
somente as provas exclusivas de empacotamento, publicação e instalação pública.

## Escopo

O escopo de promoção continua sendo o fechamento da campanha ST.0–ST.16 e os
gates listados abaixo. O código atual da branch também contém dois recortes
experimentais ainda sem promoção: lowering de `move || ...` sem parâmetros e
com capturas próprias `Send` para `ThreadJob`, e produtos LLVM freestanding
para `thumbv6m-none-eabi`, `thumbv7em-none-eabihf` e
`riscv32imc-unknown-none-elf`. Closures gerais,
alvos arbitrários e suporte de runtime freestanding não fazem parte desses
recortes. A presença da implementação na branch não comprova suporte publicado;
o contrato final da candidata precisa declarar explicitamente se esses recortes
serão promovidos ou permanecerão experimentais.

A mesma preparação aposenta identificadores de socket, reactor, supervisor e
waker por geração, exige SHA-256 externo e `BLAKE3SUMS` interno antes da
publicação atômica dos instaladores, e divide o codegen LLVM, o runtime C de
tasks e o hash estrutural sem alterar IR, C ou bytes de hash.

Os produtos freestanding disponíveis no código são objeto, LLVM IR e
`staticlib`; ELF exige `--linker-script` fornecido pelo usuário. O compilador
não adivinha o mapa de memória do chip. Em alvo bare-metal, `std.thread` e
`std.fs` são rejeitados com T099; isso não equivale a uma biblioteca `std`
freestanding.

A anotação `@Export`/`@Export("nome")` entra como recorte experimental desta
candidata: uma única anotação publica a função com símbolo plano, ABI C do
alvo e `nounwind`, aceitando primitivos de largura fixa, `bool`, ponteiros crus
e retorno `void`. Structs por valor e fatias continuam rejeitados com T049 até
o classificador reverso de ABI; a fronteira é validada em vez de presumida.
