# Error O017: Access to `static mut` Requires `unsafe`

Accessing or mutating a module-level mutable global variable (`static mut`) is
an unsafe operation because it can cause data races across threads and aliasing
violations. It must live inside an `unsafe` block.

## Incorrect Code Example

```arandu
static mut COUNTER: int = 0

func increment() {
    COUNTER = COUNTER + 1
}
```

## Correct Code Example

```arandu
static mut COUNTER: int = 0

func increment() {
    unsafe {
        COUNTER = COUNTER + 1
    }
}
```
