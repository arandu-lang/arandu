# Error T045: Compile-Time Resource Limit Exceeded

Compile-time evaluation is deterministic and bounded. Public defaults are
1,000,000 fuel units and 1,000,000 value slots per obligation family, shared
between roots and generated occurrences, with at most 128 frames per evaluation.
Drivers can configure positive limits through CLI `--ctfe-fuel`, `--ctfe-frames`,
`--ctfe-values`, LSP initialization options `ctfe`, or the Rust analysis/web API.
An item may contain at most 4,096 explicit roots. Static expansion permits at
most 4,096 occurrences and 16 nested staging contexts. Occurrences divide the
family budget by their actual ancestor domain cardinalities, without rounding up. These are interpreter limits,
not elapsed time or host-memory heuristics.

Declaration dependencies have a separate ceiling of 16 nested global/header
queries, including dependencies reached through generic helpers, static
conditions and computed arguments. This bounds native compiler query nesting
before the VM starts executing. The diagnostic shows up to eight recent
causal declaration locations. A repeated declaration in the causal path is a
cycle (T044), rather than resource exhaustion. Discarded static branches do not
consume this depth allowance.

Fuel and frame exhaustion include a hint to inspect infinite recursion and
loops without a terminating condition. Live-value/allocation limits instead
suggest reducing intermediate data; they are not evidence of an infinite loop.

An infinite loop, excessive recursion or a large calculation can exhaust a
limit. Simplify the computation, make the loop terminate or run the operation
at runtime. Exhaustion reports an error rather than hanging the editor or
falling back to runtime execution. Analysis cancellation is distinct from a
language error and is not memoized as a failed evaluation.
