# Error T001: Cannot Infer Type

The type checker could not determine a type: nothing in the body fixes it.

## Incorrect Code Example

```arandu
import std.alloc.vec as vec

func main(): int {
    let items = vec.Vec.new()
    return 0
}
```

```text
error[T001]: cannot infer type: type annotation needed for `T` of `new`
```

## Semantic Explanation

When a generic parameter has no argument, annotation or expected type to fix
it at its call, the checker does not give up there: the parameter becomes an
inference variable that later uses of the value bind. This compiles, because
the first `push` fixes the element type:

```arandu
let mut items = vec.Vec.new()
items.push(1)
```

A literal that meets the variable before its width is known takes the width
of a later use (`items.push(5000000000)` followed by passing `ref items` to a
function that takes `ref vec.Vec<i64>`). An integer or float variable that
nothing fixes takes `int` or `float`, as a literal without context does; an
operator applied to it with nothing concrete beside it settles it the same way
at that point.

T001 is reported when the body ends and a variable is still unbound in the
type of an expression or a binding. It points at the call that needed the
variable, once per variable and in the order the variables were created, and
the type becomes poison so no further error cascades from it.

Interface bounds of the generic call (`K: hash.Hash`) are checked once the
body has bound the variable, so a key type that does not implement the
interface is still `T025`, not `T001`.

Some positions still need an annotation directly:

- a closure with a parameter that has no annotation and no expected
  function type (`(x) => x`); annotating the parameters is enough, as in
  `let double = (x: int) => x * 2`, whose result comes from the body;
- a generic function used as a value without type arguments;
- a bare `nil` with no context.

## How to Fix

Annotate the binding, or pass the type argument explicitly:

```arandu
let items: vec.Vec<int> = vec.Vec.new()
let others = vec.Vec<int>.new()
```
