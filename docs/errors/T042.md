# Error T042: Unsupported Compile-Time Construct

This construct, type or operation lies outside the admitted compile-time
surface. `comptime` evaluates pure bool, integer, IEEE float and void values,
immutable literal-backed text/byte views, and admitted tuples, fixed arrays and
closed Copy structs/enums, including admitted `Option` and `Result` payloads.
Arbitrary references and mutable/owned heap resources,
runtime destructors and unsupported intermediate types do not become eligible
merely because the final result is a scalar.

Computed generic arguments use `count<comptime (expr)>()`, with parentheses
around the expression. Concrete generic instances can supply dependent values
and types; match arms and lambdas retain their normal lexical capture checks.
Closed computed declaration headers, local array dimensions, plain expression
conditions, nested arguments, global constants and nested explicit roots have
staging contexts. Dependent function, struct, enum and alias headers freeze
against concrete generic arguments before final call typing and layout.
Computed arguments in pattern/loop headers use the incoming lexical scope; runtime bindings remain forbidden captures (T043). Unsupported constructs never fall back to runtime evaluation.

```arandu
func example(): void {
    let borrowed = comptime {
        let value = 42
        return ref value // a reference to a CTFE local cannot be frozen
    }
}
```

Use an admitted value computation or keep the unsupported operation at runtime.
The compiler never silently executes a rejected compile-time root at runtime.
Static `comptime if` resolves/types only the selected body. Finite `comptime for`
expansion accepts integer half-open ranges and fixed Copy arrays. Array elements
may be admitted frozen structs, enums, strings or nested arrays. Inclusive ranges,
arbitrary iterable resources and mutable iteration bindings remain unsupported. An ordinary `if` or loop inside
`comptime { ... }` does not discard type checking of its branches.
