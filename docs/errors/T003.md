# Error T003: Incompatible Argument

This error occurs when passing an argument type that does not match the parameter type of the called function.

## Incorrect Code Example

```arandu
func greet(name: str) {}
func main() {
    greet(42)
}
```

## Semantic Explanation

Functions have strict type signatures. The types of arguments at the call site must unify with the parameter types in the function definition.

Computed compile-time arguments must produce an admitted frozen value whose
type matches the declared parameter domain. Non-negative integers retain
`Const(u64)` compatibility; signed integers, booleans and admitted closed Copy
aggregates/enums use structural frozen keys. T003 rejects unsupported value
kinds; it does not reject every negative or boolean value. T011 separately
checks the declared parameter type/range, including target-sized `usize`/`isize`.
See the [public comptime contract](../arandu-comptime-core-v0.1.md).

## How to Fix

Pass the expected type:

```arandu
func greet(name: str) {}
func main() {
    greet("Bruno")
}
```
